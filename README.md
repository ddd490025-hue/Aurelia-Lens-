# Aurelia Lens — Creative Studio

Responsive single-page creative studio website based on the Aurelia Lens blush-pink Figma direction.

## Included
- Sign In, Sign Up, Forgot Password, Reset Confirmation
- Home, About Us, Services, Service Detail
- Portfolio with filters
- Project Detail and Case Study
- Pricing and Contact with success state
- Responsive mobile menu
- Password show/hide
- Smooth transitions and responsive layouts

## Deployment
This is a static site and is configured for GitHub Pages through GitHub Actions. Pushes to `main` trigger the Pages deployment workflow.

## Local preview
Open `index.html` in a browser or serve the folder with any static HTTP server.
